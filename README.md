# QuickNotes App

QuickNotes is a simple web application that allows users to create and organize notes by category. It is built using HTML, CSS, and JavaScript. The application stores notes in the browser using localStorage, allowing them to remain available after refreshing the page.

## Features

- **Add notes:** Create notes by entering text and selecting a category.
- **Categories:** Organize notes into Personal, Work, and Study categories.
- **Input validation:** Prevent empty notes and notes exceeding 200 characters.
- **Delete notes:** Remove notes that are no longer needed.
- **Note counter:** Display the number of saved notes.
- **Search notes:** Find notes by text using case-insensitive search.
- **Local storage:** Save notes in the browser and load them when the page opens.
- **Responsive design:** Use a layout designed to work on different screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run Locally

1. Clone or download this repository to your computer.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
4. Add notes, select categories, search for notes, and test the delete functionality.
